# 🏢 ระบบบัญชีกลางและจัดการการเงินรวม (Multi-Company Accounting Hub)

เว็บแอปพลิเคชัน SPA (Single-Page Application) สไตล์ Modern Minimal โทนสีกรมท่า-น้ำเงินระดับมืออาชีพ รองรับภาษาไทย 100% ออกแบบสถาปัตยกรรม **Multi-Tenant Workspace** สำหรับกลุ่มบริษัทในเครือ (Holding Group) พร้อมระบบสิทธิ์ผู้ใช้งาน 4 ระดับ, การบันทึกภาษีไทย (VAT 7% และหัก ณ ที่จ่าย WHT 1%, 2%, 3%, 5%), แดชบอร์ดวิเคราะห์เปรียบเทียบผลประกอบการ, การพิมพ์รายงานงบการเงินมาตรฐาน A4 และเชื่อมต่อฐานข้อมูลคลาวด์ **Firebase Cloud Firestore** และโฮสติ้งบน **Vercel** แบบ Realtime

---

## 🌟 ฟีเจอร์เด่นของระบบ (Key Features)

### 1. โครงสร้างและการแยกบริษัท (Multi-Tenant Workspace)
- **ระบบแชร์ลิงก์ / รหัสเชิญ (Direct Workspace & Invite Link):**
  - ส่งลิงก์เฉพาะให้พนักงานหรือผู้บริหารแต่ละบริษัทเพื่อล็อกอินเข้าสู่ Workspace เฉพาะของตนเอง
  - ระบบจะแยก Company ID อย่างเคร่งครัด ผู้ใช้บริษัท A จะไม่สามารถมองเห็นข้อมูลของบริษัท B
  - มีปุ่ม **"คัดลอกลิงก์เชิญ (Copy Invite Link)"** ได้ทันทีจากหน้าจอ
- **รองรับบริษัทในเครือ:**
  - 💻 **บริษัท สยามเทคโนโลยี โซลูชั่น จำกัด** (`comp_tech` / รหัสเชิญ: `INV-TECH-2026`)
  - 🚚 **บริษัท สยาม โลจิสติกส์ เอ็กซ์เพรส จำกัด** (`comp_logistics` / รหัสเชิญ: `INV-LOGIS-2026`)
  - 🛍️ **บริษัท สยาม รีเทล คอมเมิร์ซ จำกัด** (`comp_retail` / รหัสเชิญ: `INV-RETAIL-2026`)

### 2. บทบาทและสิทธิ์ผู้ใช้งาน 4 ระดับ (RBAC)
1. **Super Admin / บัญชีกลาง (HQ Account):**
   - ดูแดชบอร์ดภาพรวมรวมทุกบริษัท (Consolidated View)
   - สลับเข้าดูและแก้ไขข้อมูลของทุกบริษัทได้อิสระ
   - จัดการสร้าง/ลบบริษัท และกำหนดสิทธิ์ผู้ใช้งาน
2. **Company Manager (ผู้บริหารบริษัท):**
   - ดูข้อมูลเฉพาะบริษัทตนเอง
   - อนุมัติรายการเบิกจ่ายและใบแจ้งหนี้ (Approve / Reject)
   - ดูงบกำไร-ขาดทุนของบริษัทตนเอง
3. **Company Accountant (เจ้าหน้าที่บัญชี):**
   - บันทึกรายรับ-รายจ่าย พร้อมแนบหลักฐาน (สลิป/ใบเสร็จ/ใบกำกับภาษี)
   - คำนวณ VAT 7% (รวมใน / แยกนอก) และภาษีหัก ณ ที่จ่าย WHT อัตโนมัติ
   - ส่งคำขอเบิกจ่ายเพื่อให้ผู้บริหารอนุมัติ
4. **Auditor (ผู้ตรวจสอบบัญชีรับอนุญาต):**
   - เข้าดูข้อมูลและดาวน์โหลด/พิมพ์รายงาน A4 ได้อย่างเดียว (Read-only)

### 3. ระบบรายงานและการพิมพ์ทางการบัญชี (Reports & Print Engine)
- **งบกำไรขาดทุน (Profit and Loss Statement):** ออกแบบจัดหน้าพิมพ์ A4 สวยงาม พร้อมแสดงสัดส่วนร้อยละ
- **รายงานสรุปภาษีซื้อ-ภาษีขาย (ภ.พ. 30 / ภ.ง.ด. 3/53):** สรุปยอดภาษีขาย ภาษีซื้อ และภาษีที่ต้องชำระ/ขอคืน พร้อม**บล็อกลายเซ็นผู้จัดทำบัญชี, ผู้ตรวจสอบบัญชี (CPA) และกรรมการผู้มีอำนาจลงนาม**
- **ส่งออกไฟล์ CSV/Excel:** รองรับ UTF-8 ภาษาไทย 100% เปิดใน Microsoft Excel ได้ไม่เพี้ยน

### 4. การเชื่อมต่อ Firebase Cloud Firestore
- เชื่อมต่อ **Firebase Firestore Database** (Project: `companyhub-ca1b0`)
- ซิงค์ข้อมูลบริษัท ผู้ใช้ และธุรกรรมแบบ 2-Way Realtime ถาวรข้ามอุปกรณ์
- ข้อมูลอัปเดตตรงถึงคลาวด์ทันทีที่มีการเปลี่ยนแปลง
- รองรับการแก้ไขและจัดการหลายลิงก์สำหรับแต่ละบริษัท (ระบบหน้าบ้าน, หลังบ้าน, ระบบย่อย)

## 🚀 วิธีการเริ่มใช้งาน (Getting Started)

### วิธีที่ 1: รันด้วย Python Local Server (แนะนำ)
เปิด Terminal ในโฟลเดอร์นี้ แล้วรันคำสั่ง:
```bash
python3 server.py
```
เปิดบราวเซอร์ไปที่: `http://localhost:8000`

### วิธีที่ 2: เปิดไฟล์ `index.html` โดยตรง
ดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดใช้งานบนบราวเซอร์ (Chrome, Safari, Edge, Firefox) ได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมใดๆ เพิ่มเติม

## 🔗 ตัวอย่างการทดสอบ Direct Workspace URL (ลิงก์เฉพาะบริษัท)

คุณสามารถทดสอบการจำลองเข้าใช้งานเฉพาะบริษัทผ่านพารามิเตอร์ URL ได้ดังนี้:
- **บริษัท สยามเทคโนโลยี โซลูชั่น จำกัด:**
  `http://localhost:8000/index.html?cid=comp_tech&invite=INV-TECH-2026`
- **บริษัท สยาม โลจิสติกส์ เอ็กซ์เพรส จำกัด:**
  `http://localhost:8000/index.html?cid=comp_logistics&invite=INV-LOGIS-2026`
- **บริษัท สยาม รีเทล คอมเมิร์ซ จำกัด:**
  `http://localhost:8000/index.html?cid=comp_retail&invite=INV-RETAIL-2026`

*หมายเหตุ: สามารถใช้แถบ "จำลองสิทธิ์" ด้านบนของหน้าจอ เพื่อสลับโปรไฟล์ทดสอบทั้ง 4 บทบาทได้สะดวกรวดเร็ว*
